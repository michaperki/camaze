Three real integrations, not a generic connector

Each provider, read the way it actually reports cost

Anthropic
Admin API

Read via the Admin API's cost report endpoint — an organization Admin key, not a regular API key.

OpenAI
Costs API

Read via the organization Costs API, using an Admin key from your OpenAI organization settings.

Google
BigQuery export

Read from your BigQuery billing export — Google has no cost API, so camaze queries the export table your project already writes to.

Your keys

Validated, encrypted, never round-tripped

Each key is checked against the provider's own API before camaze saves it, then encrypted at rest. camaze never sends a saved key back to your browser in full — only a last-4 hint, so you can tell which one is connected without ever seeing it again. Connected keys are what power everything else on this site: cost data, alerts, forecasts, and attribution.

Costs no API reports

Fixed subscriptions, entered once

Some AI spend never shows up in a usage API at all — a flat monthly seat license is the common case. camaze lets you record those directly, and keeps them split from metered usage everywhere: in the chart, in the total, and in the forecast, since a fixed cost can't spike the way usage can.
