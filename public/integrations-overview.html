Google
BigQuery export

Read from your BigQuery billing export — Google has no cost API, so camaze queries the export table your project already writes to.

Your keys

Validated, encrypted, never round-tripped

Each key is checked against the provider's own API before camaze saves it, then encrypted at rest. camaze never sends a saved key back to your browser in full — only a last-4 hint. Connected keys are what power everything else on this site: cost data, alerts, forecasts, and attribution.
