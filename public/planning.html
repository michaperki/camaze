The short version

Usage and fixed subscriptions are forecast differently and summed into one month-end number, then colored against the budget you set — green, yellow, or red.

How the forecast is built

Usage and subscriptions, forecast differently

A flat monthly subscription and metered API usage don't behave the same way, so camaze doesn't forecast them the same way. Usage is extrapolated from your run-rate so far this month. A subscription's daily rate is close to constant, so camaze projects it linearly instead. The two projections are computed separately, then summed into one month-end number.
