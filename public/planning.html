How the forecast is built

Usage and subscriptions, forecast differently

A flat monthly subscription and metered API usage don't behave the same way, so camaze doesn't forecast them the same way. Usage is extrapolated from your run-rate so far this month, since it can spike or slow down. A subscription's daily rate is close to constant, so camaze projects it linearly instead — extrapolating a fixed cost like it might vary would just add noise. The two projections are computed separately, then summed into one month-end number.
